# 🏢 Professional Experience

### Software Engineer — Lycadigital India Private Limited

**January 2024 – July 2026 | Bengaluru, India**

* Architected a unified **Next.js, React.js and TypeScript** codebase supporting portals across **16 countries and 4 locales per market**.
* Built reusable frontend components and dynamic product catalog experiences for SIM plans and bundles.
* Integrated **headless PIM/CMS APIs** using Axios interceptors for authentication and error handling.
* Improved frontend performance by approximately **50% LCP reduction** and eliminated CLS through asset optimization, code-splitting and layout stabilization.
* Implemented **CMS-driven feature flags** for country-specific feature rollouts without requiring production redeployments.
* Built and maintained microservices using **Node.js, Nest.js and Express.js** for transactions, payments, user lifecycle and tariff logic.
* Integrated third-party payment and credit APIs with **retry, timeout and audit-log mechanisms**.
* Designed an extensible validation engine using **Chain of Responsibility, Factory and Builder design patterns**.
* Implemented **Redis-backed authentication sessions**, OTP/password login and **Socket.IO real-time events**.
* Worked with **PostgreSQL and MongoDB**, using TypeORM for entity modeling and optimizing indexes and queries to improve p99 latency.
